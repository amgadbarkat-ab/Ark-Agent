# Ark Agent: product docs

Ark Agent is our own company-owned AI agent platform ("digital employees"), sold as a monthly
subscription and also used internally. These docs record decisions, research and plans. Newest
decisions win; each file says when it was written.

| File | What it covers |
| --- | --- |
| [01-product-decisions.md](01-product-decisions.md) | What we decided to build: platforms, pricing, LLM providers, marketplace. Open questions. |
| [02-competitor-comparison.md](02-competitor-comparison.md) | openbot.run, Bops, Hark, James AI compared against our requirements. |
| [03-licensing.md](03-licensing.md) | What code we may legally reuse, and what we may not. |

Status of the codebase: the repo currently contains CopilotKit's OpenBot (MIT) as a **starting
point only**. It is not the product, and it needs CopilotKit's hosted Intelligence service to start,
which conflicts with decision D1 below. See 03-licensing.md and 01-product-decisions.md.
